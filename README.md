## ZenSync: AI Health Companion for Mental & Physical Health Support
ZenSync is a web-based AI health companion that provides mental health support, symptom analysis, medication checking, and nearby hospital crowd estimation using OpenStreetMap data with a clean interactive UI.

It includes features like stress scoring, symptom risk insights, drug interaction checking, and hospital search with crowd simulation, built using HTML, CSS, and JavaScript with API integration for AI responses; it is for informational purposes only and not a medical substitute.
